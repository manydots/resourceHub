## 一、功能简介

游戏账号网关，提供注册、登录、改密、管理员重置/查询账号、健康检查，可选内置网页登录器供浏览器登录。启用网页登录器后，浏览器访问 `http://<服务器IP>:5055/` 即可登录。

### 1.1 协议支持

| 传输      | 默认端口 | 用途                   | 特性                                   |
| --------- | -------- | ---------------------- | -------------------------------------- |
| TCP       | `8000`   | 持久连接，支持全部命令 | 长连接、空闲超时断开、长度前缀分帧     |
| UDP       | `5056`   | 仅健康检查             | 无连接、低延迟探活                     |
| WebSocket | `5055`   | 网页登录器，支持全部命令 | 裸 Protobuf、跨域控制、可嵌入前端静态文件 |

所有协议均采用 Protobuf 编码，**未加密传输**，建议在可信网络或通过 TLS 反代部署。共享同一套命令处理器、限流和鉴权中间件。

### 1.2 核心功能

#### 账号注册（CMD_REGISTER）

- 用户提交账号名、密码、确认密码创建新账号
- 账号仅允许字母数字（`a-zA-Z0-9`），长度 3-20 字符
- 密码长度 6-32 字符，以 MD5 哈希存储
- 两次密码必须一致，账号名唯一性校验
- 仅支持 TCP/WebSocket，不支持 UDP

#### 账号登录（CMD_LOGIN）

- 校验账号密码，成功返回游戏启动参数（launch_args）
- 返回信息：account_id、m_id、password_hash、launch_args
- 连续失败 5 次锁定账号 5 分钟（与改密共享计数）
- 密码比对采用恒定时间算法，防止时序攻击
- 未设置密码的账号返回特定提示

#### 修改密码（CMD_CHANGE_PASSWORD）

- 用户自助改密，需提供旧密码验证身份
- 新密码不能与旧密码相同
- 旧密码错误计入失败锁定（与登录共享计数）
- 仅支持 TCP/WebSocket

#### 管理员重置密码（CMD_ADMIN_RESET）

- 管理接口，无需旧密码强制重置
- 需通过 `auth_key` 授权
- 重置成功后解除账号锁定
- 仅支持 TCP/WebSocket

#### 账号信息查询（CMD_ACCOUNT_INFO）

- 管理接口，查询账号全量信息
- 返回点券、各类晶块、创建/登录时间等
- 不返回 password_hash 保护隐私
- 需通过 `auth_key` 授权
- 仅支持 TCP/WebSocket

#### 健康检查（CMD_HEALTH）

- 探测游戏服务器频道端口（channel_port）和游戏端口（game_port）是否可达
- TCP/UDP/WebSocket 均可调用，无需鉴权，不受限流
- 2 秒缓存避免高频穿透
- UDP 健康检查按源 IP 限频防反射放大

### 1.3 网页登录器

- 内置 WebSocket 端点 + 静态文件服务
- 浏览器访问 `http://<服务器IP>:5055/` 即可登录
- 前端可嵌入二进制（`internal/web/dist/`）或通过 `web_dist_dir` 指定目录
- 支持跨源 WebSocket 控制（`web_origin`）
- 生产部署建议通过反代提供 HTTPS/WSS

### 1.4 安全特性

- **管理授权**：`auth_key` 默认值拒绝启动，强制设置强密钥
- **IP 限流**：每 IP 每分钟 60 次请求上限（可配置），分片式固定窗口算法
- **时间戳防重放**：非 HEALTH 命令强制 60 秒窗口校验
- **账号锁定**：连续失败 5 次锁定 5 分钟（登录与改密共享计数）
- **命令白名单**：按需开关命令，HEALTH 始终豁免
- **密码安全**：恒定时间比对、请求日志脱敏

### 1.5 数据存储

- 内嵌 SQLite 单文件存储，纯 Go 驱动无 CGO 依赖
- 支持 WAL 模式并发读、busy_timeout 串行写
- 可选启动时自动建表（schema 幂等迁移）
- 可接入已有游戏数据库（不改表结构）

### 1.6 日志系统

- 按级别拆分独立文件：debug.log / info.log / warn.log / error.log
- 自动轮转与压缩（lumberjack）
- 可配置保留数量、保留天数、单文件大小
- 敏感字段（密码等）自动脱敏

## 二、文件清单与部署

### 2.1 支持平台

| 平台    | 架构  | 二进制文件名  | 说明                     |
| ------- | ----- | ------------- | ------------------------ |
| macOS   | arm64 | `gateway`     | Apple Silicon (M1/M2/M3) |
| Linux   | amd64 | `gateway`     | x86_64 服务器            |
| Windows | amd64 | `gateway.exe` | 64 位 Windows            |

网关采用纯 Go SQLite 驱动，无 CGO 依赖，生成单文件二进制，无需安装运行时环境。

### 2.2 文件清单

| 文件                                  | 必需 | 说明                 |
| ------------------------------------- | :--: | -------------------- |
| `gateway`（Windows 为 `gateway.exe`） |  是  | 网关主程序           |
| `config.yaml`                         |  是  | 运行配置             |
| `item_schema.sql`                     |  否  | 建表 SQL，首次建库用 |

建议同目录放置，便于相对路径解析。

### 2.3 部署步骤

1. **解压并修改配置**：`admin.auth_key` 改为强密钥（默认值拒绝启动）；默认 `tcp_port` 为 `8000`（高位端口），普通用户即可运行，无需 root。

2. **前台启动验证**：看到监听地址与"数据库连接成功"即表示启动成功，`Ctrl+C` 停止。不带参数时默认读取 `config.yaml`，`./gateway` 等价于 `./gateway -config config.yaml`。

   ```bash
   ./gateway -config config.yaml        # macOS/Linux
   gateway.exe -config config.yaml      # Windows
   ```

3. **停止**：`kill <PID>`（macOS/Linux）/ `taskkill /pid <PID>`（Windows），SIGTERM 优雅关闭并刷盘。

4. **生成 16 位随机密钥**：

   macOS/Linux：

   ```bash
   LC_ALL=C tr -dc 'A-Za-z0-9' </dev/urandom | head -c 16; echo
   ```

   Windows PowerShell：

   ```powershell
   -join ((48..57)+(65..90)+(97..122) | Get-Random -Count 16 | % {[char]$_})
   ```

## 三、配置说明

`config.yaml`，**环境变量优先级更高**（适合容器化部署）。完整模板见 `config.example.yaml`，全部参数说明如下。

### server 段

| 配置项                     | 默认值            | 说明                                                     |
| -------------------------- | ----------------- | -------------------------------------------------------- |
| `host`                     | `0.0.0.0`         | 监听地址，`0.0.0.0` = 所有网卡                           |
| `tcp_port`                 | `8000`            | TCP 端口，默认高位端口无需 root                             |
| `udp_port`                 | `5056`            | UDP 端口，仅健康检查                                     |
| `game_ip`                  | `127.0.0.1`       | 游戏服务器 IP，登录返回给客户端                          |
| `channel_port`             | `7001`            | 频道端口，登录返回 + 健康检查                            |
| `game_port`                | `10011`           | 游戏端口，健康检查                                       |
| `game_health_check_ip`     | (空，沿用 game_ip) | 健康检查专用 IP；游戏 IP 为公网时同机探活填 `127.0.0.1`  |
| `health_check_timeout_sec` | `5`               | 健康检查 TCP 探测超时（秒）                              |
| `max_payload_bytes`        | `1048576`         | 单条消息最大字节（1MB）                                  |
| `conn_idle_timeout_sec`    | `300`             | TCP 连接空闲超时（秒）                                   |
| `command_whitelist`        | 全部命令          | 命令白名单；空 = 仅健康检查，删除某项即禁用该命令        |
| `web_enabled`              | `false`           | 是否启动网页登录器                                       |
| `web_port`                 | `5055`            | 网页 HTTP 端口                                           |
| `ws_path`                  | `/gateway`        | WebSocket 路径，须以 `/` 开头                            |
| `web_origin`               | `["*"]`           | 允许跨源 WS 的 Origin 列表，生产收紧为具体域名           |
| `web_dist_dir`             | (空，使用嵌入 dist) | 前端静态文件目录，覆盖编译时嵌入的 dist                  |
| `trust_proxy_headers`      | `false`           | 反代场景信任 `X-Real-IP`/`X-Forwarded-For`，按真实 IP 限流 |

#### command_whitelist 命令详情

网关支持以下命令，通过 `command_whitelist` 控制启用/禁用：

| 命令名                | 功能           | 协议支持         | 鉴权要求         | 说明                                   |
| --------------------- | -------------- | ---------------- | ---------------- | -------------------------------------- |
| `CMD_HEALTH`          | 健康检查       | TCP/UDP/WebSocket | 无               | 始终豁免白名单检查，不受限流           |
| `CMD_REGISTER`        | 账号注册       | TCP/WebSocket    | 无               | 创建新账号，账号名唯一性校验           |
| `CMD_LOGIN`           | 账号登录       | TCP/WebSocket    | 无               | 校验密码，返回游戏启动参数             |
| `CMD_CHANGE_PASSWORD` | 修改密码       | TCP/WebSocket    | 无（需旧密码）   | 用户自助改密，旧密码错误计入锁定       |
| `CMD_ACCOUNT_INFO`    | 账号信息查询   | TCP/WebSocket    | `auth_key` 授权  | 管理接口，查询账号全量信息             |
| `CMD_ADMIN_RESET`     | 管理员重置密码 | TCP/WebSocket    | `auth_key` 授权  | 管理接口，强制重置密码，无需旧密码     |

配置示例：

```yaml
server:
  command_whitelist:            # 启用全部命令
    - CMD_HEALTH
    - CMD_REGISTER
    - CMD_LOGIN
    - CMD_CHANGE_PASSWORD
    - CMD_ACCOUNT_INFO
    - CMD_ADMIN_RESET
```

```yaml
server:
  command_whitelist:            # 仅启用注册和登录
    - CMD_REGISTER
    - CMD_LOGIN
```

```yaml
server:
  command_whitelist: []         # 空列表，仅健康检查可用（CMD_HEALTH 豁免）
```

> 注意：`CMD_HEALTH` 始终可用，无需显式配置。删除某项即禁用该命令，客户端调用时返回 `3008`（该命令未开放）。

### database 段

| 配置项                  | 默认值              | 说明                                                             |
| ----------------------- | ------------------- | ---------------------------------------------------------------- |
| `path`                  | `./data/inventory.db` | SQLite 路径，相对路径基于工作目录                              |
| `schema_file`           | `./item_schema.sql` | 建表 SQL，`schema_enabled` 开启时执行                            |
| `schema_enabled`        | `false`             | 启动时应用 schema（幂等）；首次建库置 `true`，日常保持 `false`   |
| `max_open_conns`        | `4`                 | 最大连接数                                                       |
| `max_idle_conns`        | `2`                 | 最大空闲连接数                                                   |
| `conn_max_idle_sec`     | `300`               | 空闲连接存活秒数                                                 |
| `conn_max_lifetime_sec` | `1800`              | 连接最大存活秒数（0 = 不限制）                                   |

### auth 段（账号策略）

| 配置项                  | 默认值 | 说明                       |
| ----------------------- | ------ | -------------------------- |
| `min_username_length`   | `3`    | 账号最小长度               |

| `min_password_length`   | `6`    | 密码最小长度               |
| `max_password_length`   | `32`   | 密码最大长度               |

### admin 段

| 配置项     | 默认值          | 说明                                       |
| ---------- | --------------- | ------------------------------------------ |
| `auth_key` | `change-me-...` | 管理授权密钥，**必须修改**，默认值拒绝启动 |

### rate_limit 段

| 配置项                | 默认值 | 说明               |
| --------------------- | ------ | ------------------ |
| `enabled`             | `true` | 是否启用限流       |
| `requests_per_minute` | `60`   | 每 IP 每分钟请求上限 |

### log 段

| 配置项         | 默认值   | 说明                                                      |
| -------------- | -------- | --------------------------------------------------------- |
| `enabled`      | `false`  | 是否开启日志，关闭则无任何日志                            |
| `level`        | `info`   | `debug`/`info`/`warn`/`error`，可写成列表，取最宽松级别   |
| `dir`          | `./logs` | 日志目录                                                  |
| `max_size_mb`  | `100`    | 单文件最大体积，超过后轮转                                |
| `max_backups`  | `7`      | 保留的旧日志文件数                                        |
| `max_age_days` | `30`     | 旧日志保留天数                                            |
| `compress`     | `true`   | 旧日志是否 gzip 压缩                                      |

日志按级别拆分为独立文件（`debug.log`/`info.log`/`warn.log`/`error.log`），仅创建 ≥ 阈值的级别文件；自动轮转。

> **路径解析**：相对路径基于启动时的工作目录，建议先 `cd` 到部署目录或用绝对路径。

## 四、数据库

采用 SQLite 单文件存储。

- **接入已有游戏库**：`schema_enabled` 保持 `false`，配置 `database.path` 指向该库即可，不改表结构。
- **首次建库**：置 `schema_enabled: true` 启动建表，完成后改回 `false`。
- **Windows 路径**推荐正斜杠 `/`，反斜杠在双引号内需转义 `\\`。

## 五、网页登录器（可选）

`web_enabled: true` 后，`web_port` 同时提供前端页面与 `/gateway` WebSocket 通道，浏览器访问 `http://<服务器IP>:5055/` 即可登录。前端通常已嵌入二进制；未嵌入则用 `web_dist_dir` 指定目录。

### 5.1 管理员重置账号密码（以 10038 为例）

忘记密码或账号被锁定需要管理员介入时，可直接在网页登录器中重置，无需旧密码。本质是前端经 `/gateway` WebSocket 发送 `CMD_ADMIN_RESET` 请求，服务端校验 `auth_key` 后强制改密并解除锁定。

操作步骤：

1. 确保已启用网页登录器（`web_enabled: true`），浏览器打开 `http://<服务器IP>:5055/`。
2. 切换到"重置密码"页签，按下表填写：

   | 输入项   | 内容                                                             |
   | -------- | ---------------------------------------------------------------- |
   | 账号     | `10038`                                                          |
   | 管理密钥 | `admin.auth_key` 的值（或环境变量 `GATEWAY_ADMIN_AUTH_KEY`）     |
   | 新密码   | 6-32 位                                                          |
   | 确认密码 | 与"新密码"一致                                                   |

3. 点击"重置"，成功后提示"密码已重置，请使用新密码登录"，即可用新密码登录。

> 说明：
>
> - 对应命令 `CMD_ADMIN_RESET`，请求体 `AdminResetPasswordRequest{m_id, new_password, new_password_confirm}`，请求头 `auth_key` 填管理密钥；该命令未在 `command_whitelist` 中时返回 `3008`。
> - `auth_key` 不匹配返回 `1010`，账号不存在返回 `1007`，密码长度不符返回 `1005`，重置成功会同步解除账号锁定（`1012`）。
> - 管理密钥经 WebSocket 明文传输，仅建议在内网或已启用 HTTPS/WSS 反代的环境操作。

## 六、常见问题与错误码

### 常见问题

| 现象             | 排查                                                |
| ---------------- | --------------------------------------------------- |
| 启动即退、无输出 | `auth_key` 默认值或端口占用；前台启动查看错误       |
| 后台启动无法访问 | 日志关闭且输出丢弃；先前台排错或开启日志            |
| 端口监听失败     | `tcp_port` 被占用或防火墙拦截，改用其他空闲端口             |
| 请求返回 `3002`  | 限流，调高 `requests_per_minute` 或排查异常客户端   |
| 请求返回 `3006`  | 时间戳超 60s 窗口                                   |
| 请求返回 `1010`  | 管理命令 `auth_key` 不匹配                          |
| 请求返回 `1012`  | 账号锁定（连续失败 5 次锁定 5 分钟）                |
| 请求返回 `3008`  | 命令未在白名单                                      |
| 反代后限流失效   | 启用 `trust_proxy_headers`                          |

### 错误码

| 码 ｜含义                                                       |
| ------------------------------------------------------------ |
| `0` ｜成功                                                       |
| `1001` ｜账号不能为空                                           |
| `1002` ｜账号长度不符合要求                                     |
| `1003` ｜账号已存在                                             |
| `1004` ｜密码不能为空                                           |
| `1005` ｜密码长度不符合要求                                     |
| `1006` ｜两次密码输入不一致                                     |
| `1007` ｜账号不存在                                             |
| `1008` ｜密码错误                                               |
| `1009` ｜新密码不能与旧密码相同                                 |
| `1010` ｜授权 auth_key 无效                                     |
| `1011` ｜账号包含非法字符                                       |
| `1012` ｜账号已被临时锁定，请稍后再试                           |
| `3002` ｜请求过于频繁                                           |
| `3003` ｜未知命令                                               |
| `3004` ｜该命令不支持 UDP 传输                                  |
| `3005` ｜请求解码失败                                           |
| `3006` ｜请求时间戳无效                                         |
| `3007` ｜响应编码失败                                           |
| `3008` ｜该命令未开放                                           |
| `3009` ｜请求体过大                                             |
| `5001` ｜数据库操作失败                                         |
